# Готовые темы

Во вкладке «Готовые» в [[Студия оформления]] двенадцать тем. Клик подставляет её целиком: цвета, шрифт, скругление, фон и вид карточек.

| Тема | Характер |
| --- | --- |
| Обсидиан | Тёмный фон, бирюзовый акцент, обычная сетка. С неё всё начинается. |
| Берёза | Светлая бумага, зелёный акцент, шрифт Literata, тень у карточек. |
| Незерит | Почти чёрный с красным, шрифт Unbounded, острые углы, заметное движение. |
| Скалк | Тёмный бирюзовый, сетка на фоне, стеклянные карточки. |
| Вишня | Тёмно-розовый, крупное скругление, Literata. |
| Медь | Тёплый тёмный, медный акцент, Unbounded. |
| Полночь | Синий тёмный, стеклянные карточки. |
| Кварц | Светлый тёплый, контур карточек, терракотовый акцент. |
| Энд | Пиксельный шрифт, прямые углы, плотный макет, без анимации, сетка. |
| Пустыня | Песочный светлый, Literata, тень. |
| Глубокий сланец | Серый камень, почти без скругления, плотный макет. |
| Аврора | Тёмный с двумя яркими акцентами, мозаика, стекло, заметное движение. |

Правка любой из них не портит плитку: лаунчер копирует тему и дальше меняет копию. Повторный клик по плитке снова ставит чистый вариант.

Случайная тема в этот список не добавляется. Чтобы оставить её насовсем, экспортируйте файл. См. [[Импорт и экспорт тем]].
