# Что такое UltraPrism

UltraPrism — интерфейс поверх установленного ElyPrism. Исходники лаунчера лежат в каталоге `launcher`. Страница на `http://127.0.0.1:43123` читает папку ElyPrism и передаёт ей запуск, импорт и окна сборок.

Проект не связан с Prism Launcher, Ely.by и Mojang и не одобрен ими. Код лаунчера под GPL-3.0-only.

## Что есть в этой версии

- Библиотека сборок из папки ElyPrism: версия, загрузчик, группа, заметка, запуск.
- Создание пустой сборки, импорт, копирование папки, настройки Java и памяти.
- Моды, миры, ресурспаки, шейдеры, скриншоты и журнал выбранной сборки.
- Окно установленного ElyPrism для модпаков, входа в аккаунт, экспорта и удаления.
- Студия темы: палитры, цвета, шрифт, плотность, макет, фон, свой CSS.
- Это руководство.

Токены Microsoft и Ely.by в страницу не копируются. Их по-прежнему хранит ElyPrism. См. [[Запуск]].

## Где лежат данные

Всё, что вы меняете в окне, остаётся в браузере на этом компьютере:

| Что | Куда |
| --- | --- |
| Тема | ключ `ultraprism.theme.v1` |
| Сборки, ники, порядок разделов | ключ `ultraprism.library.v1` |
| Карточки миров | ключ `ultraprism.worlds.v1` |

Три ключа нарочно разные. Запись темы в ключ миров код запрещает. См. [[Почему миры в безопасности]].
