# Свой CSS

Вкладка «CSS» принимает обычные правила. Они вставляются на страницу и живут вместе с темой.

Удобные классы, которые уже стоят в окне:

- `.up-shell` — всё окно;
- `.up-sidebar` — боковая панель;
- `.up-topbar` — шапка;
- `.up-card` — карточка сборки.

Пример, который можно вставить целиком:

```css
.up-card {
  letter-spacing: 0.02em;
}

.up-topbar {
  border-bottom-width: 2px;
}
```

## Что вырезается

Лаунчер режет запись до 8000 символов и убирает опасные куски:

- `@import` и внешние таблицы стилей;
- `javascript:`;
- старые конструкции `expression(` и `behavior:`;
- попытку закрыть тег `style` и дописать что-то после него.

Свой CSS всё равно может спрятать кнопку или сделать текст нечитаемым. **Очистить CSS** или отмена вернут предыдущий шаг. Если отмена уже не помогает, поставьте готовую тему заново: она приходит с пустым CSS.

> [!tip] Поле ввода и Ctrl+Z
> Пока курсор в поле CSS, `Ctrl+Z` отменяет букву в тексте, а не всю тему. Сначала кликните мимо поля, потом отменяйте шаг темы.
