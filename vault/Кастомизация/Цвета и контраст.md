# Цвета и контраст

Во вкладке «Цвет» одиннадцать полей. У каждого квадрат и текстовый код. Подходит `#aabbcc` и короткий `#abc`.

| Поле | Куда попадает |
| --- | --- |
| Фон | Общий фон окна |
| Карточки | Подложка карточек, меню и панелей |
| Второй слой | Подсветка пункта меню, поля, чипы |
| Текст | Основной текст |
| Приглушённый текст | Подписи, даты, вторичные строки |
| Акцент | Кнопки, активные фильтры, полоска карточки, если у сборки нет своего |
| Второй акцент | Второе свечение на фоне «Свечение» и градиент |
| Границы | Рамки |
| Опасность | Разрушительные кнопки и красная точка в проверке запуска |
| Успех | Зелёная точка в проверке запуска |
| Предупреждение | Строка слабого контраста и рамка предупреждения в мирах |

Под названием темы лаунчер считает контраст **текста и фона**:

- от 7 — спокойно читается;
- от 4.5 — нормальный контраст;
- от 3 — мелкий текст будет тяжело читать, строка становится цветом предупреждения;
- ниже — «почти сливается».

Это подсказка, не запрет. Тёмная тема с серым текстом на сером фоне останется, если вы так сохранили, но строка скажет об этом.

Свой цвет одной сборки задаётся не здесь, а на [[Страница сборки]]. Он красит только полоску этой карточки.
