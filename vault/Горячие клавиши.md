# Горячие клавиши

На Windows и Linux — `Ctrl`. На macOS — `Cmd`.

| Клавиши | Действие |
| --- | --- |
| `Ctrl+K` | Перейти к сборкам и поставить курсор в поиск |
| `Ctrl+1` … `Ctrl+5` | Открыть раздел по месту в боковой панели. Порядок меняется в [[Макет]] |
| `Ctrl+Enter` | Открыть окно [[Запуск]] |
| `Ctrl+Z` | Отменить шаг темы, если курсор не в поле ввода |
| `Ctrl+Shift+Z` | Вернуть отменённый шаг темы |

В поле названия темы, цвета, CSS и других вводах `Ctrl+Z` работает как обычная отмена текста. Кликните по пустому месту окна, если нужно отменить именно тему.

Кнопки **Отменить** и **Вернуть** в студии делают то же, что клавиши, и не зависят от того, где курсор.
